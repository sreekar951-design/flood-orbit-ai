# FloodOrbit AI - Himalayan Flood Intelligence Dashboard
### IIT Hackathon 2026 // Case Study: August 2026 Trishuli & Bhote Koshi River GLOF

A defense-grade spaceborne disaster assessment platform that combines Sentinel-1 C-band SAR radar with Copernicus WorldDEM-30 elevation data to map flash flood damage, broken bridges, and trapped populations through monsoon clouds.
